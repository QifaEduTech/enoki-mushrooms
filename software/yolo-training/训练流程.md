## 二、数据准备

### 2.1 数据格式

每张图片对应一个同名 `.txt` 标注文件：

```
data/train/
├── images/
│   ├── 001.jpg
│   └── 002.jpg
└── labels/
    ├── 001.txt      # 标注文件
    └── 002.txt
```

### 2.2 标注文件格式

每行一个目标，格式：`类别ID 中心X 中心Y 宽 高`（值归一化到 0-1）

```
0 0.45 0.52 0.30 0.25
1 0.78 0.33 0.15 0.20
```

### 2.3 类别对照表

| ID | 类别 |
|----|------|
| 0 | 金针菇白粉病 |
| 1 | 金针菇灰霉病 |
| 2 | 金针菇炭疽病 |
| 3 | 金针菇枯萎病 |
| 4 | 金针菇叶斑病 |
| 5 | 金针菇红蜘蛛 |
| 6 | 金针菇蚜虫 |

### 2.4 划分数据集

```bash
python scripts/prepare_data.py split --source /你的数据集路径 --output data
```

## 三、开始训练

```bash
# 基础训练（推荐新手）
python scripts/train.py --model yolov8n.pt --epochs 100 --batch 16

# 完整参数
python scripts/train.py \
    --model yolov8s.pt \
    --epochs 200 \
    --batch 16 \
    --imgsz 640 \
    --device 0
```

### 模型选择

| 模型 | 大小 | 速度 | 精度 | 推荐场景 |
|------|------|------|------|----------|
| yolov8n | 6MB | 最快 | 一般 | 边缘设备、测试 |
| yolov8s | 22MB | 快 | 较好 | 日常使用 |
| yolov8m | 52MB | 中等 | 好 | 服务器部署 |
| yolov8l | 87MB | 慢 | 很好 | 高精度需求 |

## 四、查看训练结果

训练完成后，结果保存在 `runs/detect/train_日期时间/` 目录：

```
runs/detect/train_20250101_120000/
├── weights/
│   ├── best.pt          # 最佳模型（用于评估和部署）
│   └── last.pt          # 最新模型（用于恢复训练）
├── results.csv          # 训练指标记录
├── results.png          # 训练曲线图

```

## 五、评估模型

```bash
python scripts/evaluate.py val \
    --model runs/detect/train_xxx/weights/best.pt \
    --split test
```

输出指标：
- **mAP50**: IoU=0.5 时的精度（越高越好，目标 > 0.7）
- **mAP50-95**: 综合精度（越高越好，目标 > 0.5）

## 常见问题

**Q: 显存不足 (OOM)**
→ 减小 batch：`--batch 8` 或 `--batch 4`

**Q: 训练太慢**
→ 用更小的模型：`--model yolov8n.pt`，或减小图片尺寸：`--imgsz 416`

**Q: 精度不够**
→ 增加训练轮数 `--epochs 200`，或用更大的模型 `--model yolov8m.pt`

**Q: 如何标注数据**
→ 推荐工具：[LabelImg](https://github.com/heartexlabs/labelImg) 或 [CVAT](https://cvat.ai/)
