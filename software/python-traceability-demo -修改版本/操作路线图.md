# 金针菇溯源二维码系统 · 操作路线图

## 一、系统组成

- 固定脚本：`server.py` + `trace_core.py`，负责启动服务、生成二维码、读取数据库、统计扫描次数
- 扫码页面：`templates/index.html`，扫码后看到的六标签追溯页面
- 业务数据：父目录 Smart-Enokimushroom 的 MySQL `enokimushroom`
- 本地状态：`trace_state.db`（只保存扫码次数、操作日志和存证）
- 二维码文件：`trace-qr.png`

## 二、启动路线

1. 进入目录：`D:\22\Smart-Enokimushroom\python-traceability-demo`
2. 双击 `run-demo.bat`
3. 等待窗口显示：
   - 本机访问地址：`http://127.0.0.1:8000`
   - 局域网访问地址：`http://<电脑IP>:8000`
   - 二维码文件：`trace-qr.png`
4. 在电脑浏览器打开 `http://127.0.0.1:8000`，确认页面能正常显示

> 如果双击后提示“服务已在运行”，说明系统已经启动，直接访问页面即可；要重启需要先停止旧服务。

## 三、扫码验证路线

1. 手机和电脑连接同一个 WiFi
2. 打开 `trace-qr.png` 二维码图片
3. 用微信或支付宝扫码
4. 手机浏览器会自动打开溯源页面
5. 核对六个标签：产品信息、生产信息、质量信息、包装信息、销售信息、信用信息
6. 每次打开页面，扫描次数会加 1

## 四、日常使用路线

1. 使用前先启动服务
2. 电脑 IP 变化后，重新启动服务，会生成新的 `trace-qr.png`
3. 停止服务：关闭黑色窗口，或在窗口里按 `Ctrl+C`
4. 页面业务数据来自主系统 MySQL，主系统里没有的字段会自动隐藏

## 五、页面检查清单

- 产品信息：产品名称、生产日期、生产企业、信用信息、生产基地
- 生产信息：每个工序都能点击展开，显示开始/结束时间、操作人、区域/设备、其它说明
- 质量信息：送检人、送检日期、检测结果在一条信息条内
- 包装信息：包装日期、数量、总重量、包装图片、二维码显示
- 销售信息：位置信息下拉块，切换销售去向后客户单位同步变化
- 信用信息：每项都是下拉框，切换后综合信用判定实时更新
- 缺失字段：项目里没有的信息不显示，不出现 `—` 或“暂无”占位

## 六、注意事项

- 固定脚本不要修改
- 手机扫码要求手机和电脑在同一网络
- 如果手机无法访问，检查 Windows 防火墙是否放行 `8000` 端口
- 页面只是展示层，数据来源是 `main_system_client.py` 只读查询主系统 MySQL
